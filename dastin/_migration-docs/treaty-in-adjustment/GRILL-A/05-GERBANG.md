# 05 · GERBANG KESIAPAN

Kriteria selesai menurut `METODE` §7.2 bukan "semua pertanyaan terjawab", melainkan **tidak ada
lagi yang menghalangi penyusunan spesifikasi**. Gerbang di bawah memakai kriteria itu.

## A-1 · Kedudukan modul dalam spesifikasi

| | |
|---|---|
| **Putusan** | GRL-01 |
| **Keadaan** | **SIAP** |
| **Sisa** | `PP-1` (pemilik pengerjaan to-spec induk) — tidak memblokir; hanya mengubah besar ongkos jadwal pada arah dampak |

## A-2 · Rekonsiliasi ADR induk

| ADR | Keadaan |
|---|---|
| **0036** | **SIAP** — GRL-02, berlaku dengan penyesuaian; mekanisme dititipkan ke E |
| **0048** | **SIAP** — GRL-03, bingkainya mati, ketiga kewajibannya hidup; butir 1 menunggu `DB-2` |
| **0040** | **SIAP** — GRL-05, berlaku dengan penyesuaian; butir 5 dilepas ke C1; `DB-6`, `DB-7` menunggu |
| **0049** | **SIAP** — GRL-06; ditutup dengan rujukan ke GRL-05 dan C1, satu klausa warisan diangkat |
| **0052** | **SIAP** — GRL-07, berlaku dengan penyesuaian; Konteksnya dikoreksi lewat `REV-2`; `DB-10` menunggu |
| **0055** | **SIAP** — GRL-08, berlaku dengan penyesuaian; daftar keadaannya dipakai apa adanya untuk versi addendum; `REV-3` memuat empat koreksi |

## A-3 · Putusan "addendum adalah versi"

| | |
|---|---|

| **Sisa** | pembatalnya hanya bisnis — `DB-3` s.d. `DB-5`. Rancangan boleh berjalan di atasnya |

## Ringkasan gerbang

| Gerbang | Keadaan |
|---|---|
| A-1 kedudukan modul | SIAP |
| A-2 rekonsiliasi ADR | **6 dari 6 selesai** |
| A-3 putusan bentuk | SIAP dari sisi ekspor |

**Cabang A DITUTUP.** Keenam ADR induk sudah diklasifikasikan (GRL-02, GRL-03, GRL-05, GRL-06,
GRL-07, GRL-08) dan `METODE` §8.6 Q1 terjawab (GRL-04). Aturan berhenti `00-LINGKUP` §6 terpenuhi.

**Yang dibawa keluar ronde A, dan harus dibaca terang - bukan disembunyikan sebagai "selesai":**

| Jenis | Butir | Ke mana |
|---|---|---|
| usulan revisi ADR | `REV-1` (ADR-0036), `REV-2` (ADR-0052), `REV-3` (ADR-0055, empat butir) | keputusan pemilik proses, tidak memblokir |
| daftar untuk dibantah | `DB-1` … `DB-10` | orang; hanya `DB-3`/`DB-4` yang dapat membatalkan putusan |
| kueri data | `UA-1` … `UA-13` | tidak satu pun memblokir rancangan |
| ekspor tambahan | `EXP-1` | menutup TDA-13, gerbang cabang C |
| titipan | cabang B, C, D, E, F, I | tertulis di `03-LUBANG` §4 |
